1. 数学基础类

这是很多计算机课程的底层支撑，尤其对算法、AI、图形学、编译原理都很重要。

建议纳入：

* 高等数学
* 线性代数
* 概率论与数理统计
* 离散数学

其中离散数学对计算机最关键，最好重点收：

* 集合与关系
* 图论
* 数理逻辑
* 组合数学
* 递归与归纳

2. 计算机核心基础课

这部分就是你知识库的主干，408 只是其中一部分。

建议纳入：

* 程序设计基础（C / C++ / Java / Python）
* 数据结构
* 算法设计与分析
* 计算机组成原理
* 操作系统
* 计算机网络
* 数据库系统原理
* 编译原理

这里面可以按“课程知识点 + 例题 + 实验 + 常见错误”组织。

3. 软件开发与工程类

如果你想让知识库更贴近本科教学和就业，这一层非常重要，很多学校都有，但考研 408 不覆盖完整。

建议纳入：

* 软件工程
* 面向对象程序设计
* 设计模式
* 数据库应用开发
* Web 开发基础
* 前后端开发基础
* 软件测试
* 项目管理基础
* UML / 系统建模

这部分特别适合做：

* 项目案例
* 实训文档
* 课程设计资料
* 开发规范与代码模板

4. 系统与底层能力类

这部分很适合提高工程能力，也能支撑你的智能辅导系统回答更深入的问题。

建议纳入：

* Linux 操作系统与常用命令
* 计算机系统基础
* 汇编语言
* 系统编程
* 并发与多线程
* 网络编程
* 分布式系统基础
* 计算机体系结构进阶

5. 人工智能与数据类

现在很多高校计算机专业都会开这类课，你既然要做智能辅导，最好提前纳入。

建议纳入：

* 人工智能导论
* 机器学习
* 深度学习
* 数据挖掘
* 大数据技术基础
* 数据分析
* 自然语言处理
* 计算机视觉基础

这部分要注意区分：

* 理论课资源
* 实验课资源
* 数学前置知识
* Python/框架实践资源

6. 安全与信息保障类

很多学校也会有相关课程，尤其网络空间安全、信息安全方向。

建议纳入：

* 信息安全导论
* 密码学基础
* 网络安全基础
* Web 安全
* 操作系统安全
* 数据安全与隐私保护

7. 交叉应用类

这类课程不是所有学校都有，但很适合扩展知识库覆盖面。

建议纳入：

* 计算机图形学
* 数字图像处理
* 人机交互
* 嵌入式系统
* 单片机
* 物联网
* 云计算
* 区块链基础
* 移动应用开发

8. 实践教学资源

这一块非常重要，很多知识库只收“知识点”，但真正有用的是“学了以后怎么做题、怎么实验、怎么做项目”。

建议单独建库：

* 实验指导书
* 课程设计文档
* 期末复习资料
* 真题与题库
* OJ 题单
* 项目案例
* 开源课程作业
* 毕设相关资料
* 面试题与八股整理

9. 通识与规范类

不是最核心，但对高校课程体系很有价值。

建议纳入：

* 学术写作与论文规范
* 科技英语
* 信息检索
* 职业素养
* 工程伦理
* 毕业设计规范
