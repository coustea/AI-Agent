---

## 一、问题诊断

### 当前知识库的问题

| 问题 | 现状 | 应该是 |
|------|------|--------|
| **教材来源** | z-library等非官方渠道 | 教育部推荐/高校指定教材 |
| **内容定位** | 实践类/工具类书籍居多 | 理论课程教材为主 |
| **知识体系** | 杂乱，缺乏系统性 | 符合计算机专业课程体系 |
| **权威性** | 缺乏权威认证 | ACM/IEEE/教育部认可 |

### 不应该包含的内容

❌ **实践类书籍**
- Java从入门到精通
- Python编程三剑客
- Vue.js Node.js全栈开发
- Redis设计与实现

❌ **非核心课程**
- 代码大全
- 人月神话
- 高性能MySQL

## 三、权威教材获取渠道

### 官方正版渠道

1. **高等教育出版社** - 教育部直属出版社
   - 官网：https://www.hep.com.cn
   - 教材：计算机组成原理、数据库系统概论等

2. **清华大学出版社** - 高校计算机教材
   - 官网：https://www.tup.com.cn
   - 教材：离散数学、软件工程导论等

3. **电子工业出版社** - 计算机类教材
   - 官网：https://www.phei.com.cn
   - 教材：计算机网络等

4. **MIT OpenCourseWare** - 免费开放课程
   - 官网：https://ocw.mit.edu
   - 教材：算法导论等

5. **GitHub开源教材** - 免费高质量
   - d2l-ai/d2l-zh（动手学深度学习）✅已有
   - nndl（神经网络与深度学习）✅已有
