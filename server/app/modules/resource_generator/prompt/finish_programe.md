| 智能体角色 (Agent) | 职责定位 | 调用的前沿AI技术/工具 | 产出的资源类型 (满足≥5种) |
| :--- | :--- | :--- | :--- |
| 🤖 统筹规划智能体(Coordinator) | 负责与学生交互，分析“四维数据”，制定学习资源生成计划，并将子任务分发给以下专家智能体；最后负责整合汇总。 | RAG（检索增强生成）、意图识别、工作流编排引擎 | (整体学习路径规划单) |
| ✍️ 文本创作智能体(Content Writer) | 根据课程内容和学生短板，撰写深度解析和拓展阅读。 | 长文本大模型、联网搜索API (获取最新文献/案例) | 1. 专业课程讲解文档<br>2. 拓展阅读材料 |
| 🕸️ 逻辑可视化智能体(Visualizer) | 将复杂的知识结构化，生成逻辑图表。 | 大模型转代码能力、PlantUML / Mermaid 渲染引擎 | 3. 知识点思维导图 |
| 🎯 评测出题智能体(Quiz Master) | 针对学生的“知识短板”，精准生成难度阶梯化的练习题及解析。 | 逻辑推理微调模型、LaTeX 渲染 (针对理工科) | 4. 不同类型练习题目 |
| 🎬 多模态媒体智能体(Media Producer) | 将抽象概念转化为直观的视听体验。 | 文本生成图像 (文生图)、AI视频生成模型 (如 Veo/Sora 类)、AI语音合成 (TTS) | 5. 多模态教学视频/动画 |
| 💻 极客实操智能体(Code/Action Expert) | 针对计算机或理工科专业，生成可运行的代码案例或沙箱实验步骤。 | 代码大模型 (Code LLMs)、代码解释器 (Code Interpreter) 沙箱 | 6. 代码类实操案例 |
