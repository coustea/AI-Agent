# 多智能体协同学习资源生成系统设计与实现方案

## 一、系统目标

本系统基于多智能体协同架构，通过与学生的自然语言交互，结合学生的专业背景、课程内容、知识短板与学习目标，自动构建个性化学习资源。系统至少生成以下六类资源：

1. 专业课程讲解文档  
2. 知识点思维导图  
3. 分层练习题目  
4. 拓展阅读材料  
5. 多模态教学视频/动画  
6. 代码类实操案例  

---

## 二、总体架构设计

```text
用户输入（专业/课程/短板/需求）
        ↓
Coordinator Agent（任务规划与调度）
        ↓
┌──────────────────────────────────┐
│         多资源生成子Agent         │
├──────────────────────────────────┤
│ 1. Content Agent（讲解文档）      │
│ 2. Mindmap Agent（思维导图）      │
│ 3. Quiz Agent（练习题）           │
│ 4. Reading Agent（拓展阅读）      │
│ 5. Media Agent（视频/动画）       │
│ 6. Code Agent（实操案例）         │
└──────────────────────────────────┘
        ↓
Learning Package（学习资源包）
```
