## ADDED Requirements

### Requirement: Sequential Step-by-Step UI Timeline
The frontend SHALL display learning path stages and nodes as a sequential timeline instead of an interactive graph tree, guiding the learner linearly.

#### Scenario: Timeline rendering
- **WHEN** user views the learning path overview page
- **THEN** they see stages and nodes listed in chronological linear order, showing statuses, and highlighting the milestone and final capstone project.
