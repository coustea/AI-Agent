## Why

目前路径规划页面的界面布局存在严重的视觉拥挤与信息冗余：
1. **内容三重冗余**：同一个节点的标题和长文本描述，在“阶段头部”、“中间节点卡片”和“右侧当前推进”三个区域同时被渲染，导致极大的视觉噪音。
2. **横向挤压严重**：采用三栏设计（左侧阶段目录、中间主列表、右侧数据指标堆叠），在常规屏幕下导致中间和右侧内容极度窄窄，文本换行密集。
3. **加载动效单调**：生成加载状态页仅有简单的百分比进度条与冗长日志，缺乏 MAS 多智能体协同工作的可视化展现。

本变更为路径规划页面提供全新的“双栏聚焦看板（Sleek Split Dashboard）”重构，彻底解决文字冗余，腾出呼吸感空间。

## What Changes

- **双栏主布局重构**：
  - **左栏（目录路线图 Roadmap）**：展示简洁的课程大纲树状图。仅渲染阶段标题与节点标题，完全不展示大段描述文本。选中的节点高亮并亮起时间轨。
  - **右栏（学习工作台 Study Station）**：聚焦当前选中节点的详细信息。这是全屏唯一展示节点长描述、学习重点和操作按钮（“生成资料”、“继续学习”、“提交测验”）的区域。
- **右栏控制面板 Tab 化**：将原先右侧垂直堆叠的多个大卡片，合并为右栏底部的一个统一 Tab 控制台（包含“学习信号”、“诊断文献”、“路线总结”），大幅减少垂直滚动。
- **MAS 动画升级**：生成路径时使用高级 SVG 拓扑动画，动态点亮画像、检索、规划、校验智能体节点，提供纯净的动画进度。
- **检索文献卡片渲染**：在“诊断文献” Tab 内，从后端 API 读取 `search_evidence` 字段，以精美卡片呈现 AI 在查证过程中的检索词、文献网页链接及文献摘要。
