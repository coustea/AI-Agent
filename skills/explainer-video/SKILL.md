# 讲解视频制作

用 `generate_explainer_video` 工具生成真实的 MP4 视频。
渲染在后台逐帧进行，完成后可下载。

## 制作流程

### 1. 先写讲解脚本

视频是线性媒介，观众不能回看，所以叙事必须比文字更紧凑：

- **开头一句**说清这个视频解决什么问题
- **中间**按概念依赖展开，每个分镜一个知识点
- **结尾**给出可以立刻动手的一步

### 2. 设计分镜

每个分镜包含三部分：

| 字段 | 作用 | 长度 |
| --- | --- | --- |
| `heading` | 分镜标题，画面上方大字 | 一句话，不超过 20 字 |
| `bullets` | 画面正文要点 | 1-5 条，每条不超过 60 字 |
| `narration` | 底部旁白字幕 | 一两句口语化说明 |

分镜数量 2-8 个，单个分镜 2-30 秒，总时长不超过 5 分钟。
不确定时长时用默认 6 秒。

**硬限制**：最多 12 个分镜，单条要点最多 400 字。超出工具会拒绝。

### 3. 按画面思考，而不是按段落

| 该做 | 不该做 |
| --- | --- |
| 一个分镜讲清一个概念 | 一个分镜塞三个概念 |
| 要点短到能一眼读完 | 把教材段落直接搬进去 |
| 旁白是口语，像在讲解 | 旁白是书面语，像在念论文 |
| 关键对比用「A vs B」结构 | 大段连续文字 |

## 参数示例

```json
{
  "title": "Go 并发模型入门",
  "subtitle": "goroutine 与 channel",
  "scenes": [
    {
      "heading": "什么是 goroutine",
      "bullets": [
        "用户态轻量线程，初始栈仅 2KB",
        "由 Go 运行时调度，不经过操作系统",
        "创建十万个也不会耗尽内存"
      ],
      "narration": "goroutine 是 Go 并发的基石，理解它的开销是掌握并发的前提。",
      "seconds": 8
    },
    {
      "heading": "Channel 的两种形态",
      "bullets": [
        "无缓冲：收发双方必须同时就绪",
        "有缓冲：缓冲区未满即可发送",
        "关闭后仍可接收剩余值"
      ],
      "narration": "选择有无缓冲，决定了通信是同步还是解耦。",
      "seconds": 8
    }
  ]
}
```

## 生成之后

- 如实告知当前状态：`queued` / `running` / `completed`。
- 渲染需要时间（一个 60 秒视频约 10-20 秒），生成中不要谎称已完成。
- 学生追问进度时用 `get_artifact_status` 查询真实进度。
- 完成后给出下载链接、分镜数与总时长。
- 如果学生要改，重新调用工具生成新视频。

## 无法实现的情况

- 视频**没有配音**，只有画面文字与字幕。需要配音时要如实说明。
- 视频**不支持嵌入图片**，全部由文字与几何图形构成。
- 需要复杂动画（转场、3D）时，说明当前能力边界。
