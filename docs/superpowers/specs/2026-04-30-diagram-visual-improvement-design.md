# Diagram Visual Improvement Design Spec

## 1. Overview
The goal is to significantly improve the visual quality of the diagrams generated by the backend `DiagramAgent` (Mermaid to PNG rendering via Playwright) without changing the core text-to-diagram architecture. The current output feels too "programmer-centric" and lacks the polish expected of a modern educational platform.

## 2. Approach: Deep Mermaid Customization (Scheme 1)
We will maintain the current pipeline (LLM -> Structured JSON -> Mermaid DSL -> Playwright PNG) but deeply customize each step to ensure high-quality visual outputs.

### 2.1 Content Richness & Structure (D)
- **Problem:** LLM sometimes generates labels that are too long, causing cramped diagrams, or too few nodes, making the diagram look sparse.
- **Solution:** 
  - Update `server/app/resource/prompts/workers/diagram.md` (and the fallback prompt in `diagram_agent.py`) to enforce strict rules on text length.
  - Require the LLM to use concise labels (e.g., max 10-12 chars) and put longer text in descriptions.
  - Suggest formatting rules (like using `<br/>` for deliberate line breaks if necessary).
  - Enforce a balanced node count (e.g., 5-12 nodes) for optimal visual density.

### 2.2 Mermaid Engine Styling & Layout (A & B)
- **Problem:** Default Mermaid themes and curve algorithms are basic.
- **Solution:** 
  - Modify `server/app/resource/mermaid_renderer.py` and `server/app/chat/diagram_render.py` (or `diagram_agent.py` HTML templates).
  - Inject a comprehensive `themeVariables` configuration into `mermaid.initialize()`. We will design a modern "educational" theme:
    - Primary colors: Soft, modern gradients or distinct educational palette (e.g., pastel blues, greens, purples).
    - Node styling: Rounded corners, subtle shadows, clean typography.
    - Edges: Switch `curve` from `basis` to `monotoneX` or `monotoneY` for smoother, more professional-looking connections in flowcharts.
  - Adjust global Mermaid settings like `useMaxWidth`, padding, and font families to use modern system fonts (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto...`).

### 2.3 External Container Design (C)
- **Problem:** The HTML wrapper around the PNG/Mermaid render is a basic purple gradient with a plain white card.
- **Solution:**
  - Redesign the HTML templates in `server/app/resource/worker_agents/diagram_agent.py` (`_build_html_with_png` and `_build_html_content`).
  - Implement a polished, modern container:
    - Use "Glassmorphism" or subtle frosted glass effects for the header.
    - Improve the typography of the title and summary (better hierarchy, lighter text colors for secondary information).
    - Add a subtle branded watermark or background pattern (using pure CSS) to make the image feel like a premium generated asset.
    - Ensure the inner diagram has proper padding so it doesn't touch the container edges.

## 3. Implementation Steps
1. Update Prompts (`diagram.md` & fallback string).
2. Update `mermaid_renderer.py` and HTML templates in `diagram_agent.py` with new Mermaid config and CSS.
3. Add specific Mermaid directives (like `%%{init: {'theme': 'base', 'themeVariables': {...}}}%%`) directly into the DSL generation logic (`app/chat/diagram_render.py`) if global initialization isn't enough for certain diagram types.
4. Test rendering locally to ensure fonts and layouts render correctly in the headless Chromium environment.
