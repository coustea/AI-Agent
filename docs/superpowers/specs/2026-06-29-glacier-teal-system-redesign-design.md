# 冰川青绿全系统视觉重设计

## 1. 背景与目标

当前前端存在钴蓝、靛紫、翠绿和黑白 shadcn 默认变量并存的问题。登录页、注册页和主应用还使用了不同的品牌名与视觉语言，首页的信息层级偏松散，能力雷达图虽然存在，但没有形成稳定的右上视觉锚点。

本次采用方案 A，先建立全局冰川青绿设计系统，再优先改造登录、注册和首页。目标是让 AI 智能学习平台显得明亮、可信、清爽且有学习产品的专业感，同时避免常见的 AI 紫色、蓝色霓虹、过度渐变、陶土橙和黑白极简风格。

设计判断如下：

- 页面类型：现有学习产品的视觉重设计
- 目标用户：需要快速理解任务、进度和能力状态的学生
- 视觉语言：冰川青绿、低噪声、清透但不苍白
- 设计系统：沿用现有 Vue 3、Tailwind v4 和 shadcn-vue，不引入第二套组件系统
- 设计参数：变化度 5、动效强度 3、信息密度 7

## 2. 第一阶段范围

第一阶段包括：

- `src/style.css`：统一全局语义颜色、字体、圆角、阴影、焦点态、按钮和表单基础样式
- `src/shared/ui/AppLogo.vue`：调整默认品牌色回退值
- `src/app/layouts/MainLayout.vue`：优化顶部导航栏，保留单行顶栏，不增加侧边栏
- `src/features/auth/views/Login.vue`：统一品牌与登录视觉
- `src/features/auth/views/Register.vue`：统一品牌与注册视觉
- `src/features/dashboard/views/Home.vue`：重新组织首页布局，并将能力雷达图固定为桌面端右上核心模块
- `src/features/auth/components/OnboardingDialog.vue`：仅在必要处替换硬编码主色，不改交互流程

第一阶段不包括：

- 后端接口、鉴权逻辑、数据模型或业务规则修改
- 路由地址、主导航标签或表单字段顺序修改
- 将 `resource` 与 `path` 的记录、详情页或持久化模型合并
- 对所有业务页面进行结构性重排
- 新增深色模式切换或主题切换功能
- 新增大型动效库或新的图标库

其他页面会先通过全局语义变量继承冰川青绿基础风格。仍有硬编码旧色的页面放入后续阶段逐页清理。

## 3. 色彩系统

### 3.1 核心色板

| 语义 | 色值 | 用途 |
|---|---|---|
| 冰川主色 | `#46B8B4` | 选中状态、图标、图表重点、轻量强调 |
| 深水鸭色 | `#205F67` | 主按钮、重要文字、需要白字承载的高对比区域 |
| 浅冰青 | `#D8F1F0` | 选中底色、提示背景、数据区域填充 |
| 页面背景 | `#F2F8F7` | 全局页面底色 |
| 高层表面 | `#FCFFFF` | 卡片、弹窗、导航和输入区域 |
| 主文字 | `#173B42` | 标题和正文 |
| 次文字 | `#58747A` | 说明、时间、辅助信息 |
| 边框 | `#C8E4E3` | 卡片、输入框、分隔线 |
| 错误珊瑚 | `#D96F5F` | 错误、危险操作、需要加强的学习提示 |

`#46B8B4` 不直接承载小号白色正文。主操作按钮使用 `#205F67` 配白字，确保对比度。亮冰青主要承担识别、选中、图表和装饰作用。

### 3.2 语义色原则

- 整个平台只使用冰川青绿作为品牌强调色。
- 路径规划的琥珀、错误的珊瑚等颜色仅保留为真实语义，不成为第二品牌色。
- 移除首页和认证页中的蓝色、紫色及大面积高饱和绿色。
- shadcn 的 `--primary`、`--ring`、`--accent`、`--chart-*` 等变量同步映射到冰川青绿体系，避免按钮继续渲染为黑色。
- 大面积表面使用偏冷的白和浅青灰，不使用纯白铺满整页，也不使用纯黑文字。

## 4. 排版、形状与层次

### 4.1 排版

- 统一使用已引入的 Geist，并使用 `PingFang SC`、`Microsoft YaHei` 等作为中文回退。
- 正文基准为 15px，辅助信息不小于 12px。
- 页面标题依靠字重、间距和颜色建立层级，不使用夸张大字号。
- 数值和雷达图指标保持清晰，避免无意义的技术终端文案。

### 4.2 圆角

- 卡片和主要容器：14px 到 16px
- 输入框和按钮：10px 到 12px
- 标签、头像和真实状态标记：全圆角

圆角按组件职责固定，不在同一层级混用锐角、超大圆角和胶囊形。

### 4.3 阴影与边框

- 优先使用浅冰青边框和留白分组。
- 阴影仅用于导航、弹窗和重要浮层，颜色带少量青绿色调。
- 普通信息区避免每块内容都套独立白卡片。
- 不使用霓虹外发光、厚重黑色阴影或大面积玻璃拟态。

### 4.4 交互状态

- hover 通过边框、浅青底色和 1px 位移反馈。
- active 使用轻微下压，不使用弹跳和夸张缩放。
- focus-visible 使用清晰的冰川青绿色焦点环。
- loading、disabled、empty 和 error 状态必须与最终组件形状一致。
- 所有动效遵守 `prefers-reduced-motion`，不使用滚动劫持。

## 5. 顶部导航

主应用继续使用顶部导航，不新增侧边栏。

- 桌面导航高度保持在 64px 到 72px。
- 品牌、主导航和用户区保持单行。
- 保留现有导航标签和路由，避免破坏用户习惯。
- 当前导航使用浅冰青底色、深水鸭文字和底部短线共同指示。
- 移除仅用于装饰的状态点和技术化系统文案。
- 时间、动态特征和用户菜单根据空间分级收缩，保证 1024px 宽度仍不换行。
- 移动端使用紧凑菜单，不引入常驻侧栏。

## 6. 登录与注册

登录和注册页面统一使用品牌名“学枢智导”与共享 `AppLogo`。不再显示 `EduAgent`、`EDU_CORE` 等并行品牌。

### 6.1 布局

- 桌面端采用约 55:45 的非对称双栏。
- 表单区保持明确的任务焦点，视觉区表达学习路径、资源生成和智能辅导的产品能力。
- 视觉区不使用假终端、假代码、AI 脑图标或紫色光球。
- 小于 768px 时折叠为单列表单，保留品牌和一句简短价值说明。

### 6.2 表单

- 标签始终位于输入框上方，placeholder 不替代标签。
- 错误信息显示在对应字段下方。
- 登录和注册的输入高度、圆角、焦点态、密码显示按钮和主操作按钮完全一致。
- 保留现有字段顺序、校验、提交逻辑、注册完成后的流程和自动填充属性。
- 提交中展示明确的加载和禁用状态。

## 7. 首页

首页采用 12 列响应式网格，提高信息密度，但不做卡片墙。

### 7.1 桌面布局

第一行：

- 左侧 8 列：今日学习指令、推荐理由、预计时间和主操作
- 右侧 4 列：能力雷达图，作为首页右上固定视觉锚点

第二行：

- 左侧 7 列：继续学习，突出当前学习内容、进度和下一步
- 右侧 5 列：最近生成资源，明确资源类型、时间和入口

第三行：

- 学习建议、每日挑战和快捷入口按内容量组合
- 使用分组、浅色块和局部分隔建立节奏，不复制三张等宽卡片

### 7.2 能力雷达图

- 桌面端始终位于首屏右上。
- 雷达线条使用深水鸭色，区域填充使用透明冰川主色。
- 网格、标签和刻度使用浅冰青与次文字色，避免蓝色和黑灰默认值。
- 保留真实能力数据和现有 ECharts 实现，不改数据计算。
- 图表容器尺寸变化时正确 resize。

### 7.3 数据与导航边界

- 保留现有 API 调用、computed 数据和加载逻辑。
- 资源入口继续进入 `/resource-detail/:id`。
- 学习路径相关入口继续进入 `/path-planner`、`/path-resource` 等路径域页面。
- 不在首页视觉重排中合并 resource 与 path 的记录或详情。

## 8. 响应式规则

- 1440px 及以上：使用完整 12 列布局，内容宽度受全局最大宽度限制。
- 1024px 到 1439px：保持雷达图在首行右侧，压缩次要导航信息。
- 768px 到 1023px：首页转为 7:5 或单列组合，优先保留学习指令和雷达图。
- 小于 768px：首页严格单列，顺序为学习指令、能力雷达、继续学习、最近资源、其他模块。
- 所有页面禁止横向滚动，触控目标不小于 40px。

## 9. 状态与可访问性

- 主按钮正文、表单标签、placeholder、错误文案和图表标签满足 WCAG AA 对比度。
- 所有可点击元素提供键盘焦点态和可理解的 aria-label。
- 骨架屏匹配最终布局，不使用只表达等待的通用圆形加载器。
- 空状态说明如何产生数据，并提供唯一的下一步操作。
- 错误状态保留原有重试能力，不因视觉重构隐藏失败原因。
- 认证页和首页的可见文案不使用长破折号字符。

## 10. 实施边界

第一阶段以样式与布局为主。允许抽取只服务于视觉一致性的局部展示组件，但不进行业务层重构。任何涉及接口、路由、数据模型、鉴权或资源持久化的变化都不属于本阶段。

工作区已有大量未提交修改。实施时只编辑目标文件，逐文件检查 diff，不覆盖或回退用户已有改动。

## 11. 验收标准

必须完成以下验证：

1. 运行 `npm run build`，通过 `vue-tsc -b` 和 Vite 构建。
2. 在 1440px、1024px、768px 和 390px 宽度检查登录、注册和首页。
3. 确认桌面首页能力雷达图位于右上，并使用冰川青绿色板。
4. 确认应用只有顶部导航，没有侧边栏。
5. 确认按钮、输入框、焦点环和 shadcn 组件不再出现黑色默认主题。
6. 确认登录、注册与主应用统一显示“学枢智导”。
7. 确认主导航标签、路由、认证流程和首页数据行为保持不变。
8. 确认 resource 与 path 的记录、详情入口和持久化边界保持独立。
9. 确认页面无横向滚动，主要操作在键盘和移动端可用。

## 12. 后续阶段

第一阶段通过后，再按访问频率清理其他页面的硬编码旧色：

1. 智能辅导与学习题库
2. 资源生成与资源详情
3. 学习路径与路径资源详情
4. 个人中心、全局画像和其他弹窗

每一阶段继续复用本规格的语义变量，不再创建页面私有品牌色。
