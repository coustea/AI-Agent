# 题库页面展示重构设计文档

## 目标
重构现有的题库模块前端展示页面，从原先单一、低视觉表现力的 Tab 选项卡平铺布局，升级为高颜值、极具互动仪式感的“聚合式控制台 (Dashboard & Portal)”设计。
在保留现有后端 API 与底层 localStorage 逻辑的前提下，实现全新的仪表盘进度可视化、高逼格 SVG 行为分析雷达图、毛玻璃质感入口卡片以及专注工作区沉浸体验。

---

## 页面整体架构

重构后的题库页面（`QuestionBank.vue`）将由原本的单级 Tab 切换结构演进为 **主控制台 Portal** 与 **专注工作区 Focus Workspace** 两层结构，由 `viewMode` 进行状态控制：

```
                    ┌─────────────────────────┐
                    │  题库页面 (viewMode)     │
                    └────────────┬────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       [ workspace / portal ]            [ workspace / focus ]
     ┌───────────────────────┐       ┌───────────────────────────┐
     │ 1. 顶部数据仪表盘      │       │ 1. 磨砂玻璃粘性返回条       │
     │    - SVG 渐变正确率环  │       │    - 面包屑导航 & 后退按钮 │
     │    - SVG 刷题行为雷达 │       │                           │
     │                       │       │ 2. 专注功能区 (5大模块)    │
     │ 2. 悬浮磨砂功能卡片网格 │       │    - 每日 / 智能 / 检索   │
     │    - 3+2 网格排列     │       │    - 组卷 / 错题本        │
     └───────────────────────┘       └───────────────────────────┘
                                                 │
                                                 ▼
                                        [ exam / fullscreen ]
                                     ┌───────────────────────────┐
                                     │ 1. 全屏禅定顶栏 + 倒计时  │
                                     │ 2. 沉浸式答题卡与选项卡片 │
                                     └───────────────────────────┘
```

## 详细设计

### 第一部分：仪表盘与 SVG 数据可视化 (Dashboard & Visuals)

控制台主页顶部重构为磨砂玻璃质感的综合仪表盘区域（`.question-bank-hero`），支持大屏左右两栏响应式布局：

1. **左栏：核心指标与渐变正确率圆环**
   - **打卡与数据面板**：展示连续打卡天数（基于本地模拟状态）、已练题数和待复习错题数。添加励志学习格言（如：“勤学如春起之苗，不见其增，日有所长”）。
   - **SVG 渐变圆环**：
     - 使用双层 SVG `<circle>`，背景为浅色轨道，顶层为带有紫色渐变发光（`--gradient-eval`）的激活环。
     - 通过绑定 `stroke-dashoffset` 计算 `stats.totalCorrect / stats.totalAttempted` 百分比，实现页面加载时顺时针平滑拉伸进度的动效。
     - 圆环圆心显示超大字号的全局正确率（如 `85%`），下方搭配小字标签。

2. **右栏：SVG 刷题行为与能力画像雷达图**
   - **多维度指标设计（全局正确率不分科目）**：为了符合后端逻辑并提供直观反馈，雷达图的 5 个顶点表示以下行为与状态指标：
     1. **练习量 (Volume)**：基于 `stats.totalAttempted` 计算，每 10 道题得 10 分，上限 100 分。
     2. **准确度 (Accuracy)**：直接对应 `stats.totalCorrect / stats.totalAttempted` 的百分比换算（0% - 100%）。
     3. **错题消灭率 (Consolidation)**：计算 `已归档错题数 / (活跃错题数 + 已归档错题数)`。若无错题，则默认为满分 100 分。
     4. **每日坚持度 (Consistency)**：基于当前是否完成了今日的“每日一题”及本地连续打卡天数计算分值。
     5. **模考应试力 (Mock Score)**：基于最近一次模拟组卷考试的得分。若未进行过模考，则显示默认基准分 50 分。
   - **SVG 绘制实现**：
     - 用 3 layer 同心五边形网格线作为背景刻度网（30%, 60%, 90%）。
     - 计算 5 个顶点对应的 `(x, y)` 坐标。
     - 使用 `<polygon>` 填充一层带有紫色发光的半透明遮罩层（`rgba(139, 92, 246, 0.15)`），边缘描边为 `1.5px` 的 `#8B5CF6`。
     - 顶点标签外露（如“准确度”、“错题消灭”），支持鼠标悬浮 Tooltip 气泡展示具体得分。

### 第二部分：卡片入口与专属专注工作区 (Cards & Focus Workspaces)

1. **磨砂玻璃卡片入口网格**
   - 包含 **每日练习**、**智能练习**、**全部题目**、**模拟组卷** 和 **错题本** 5 个卡片，在控制台呈 3+2 CSS Grid 排布。
   - **样式设计**：高对比度的毛玻璃卡片（`backdrop-filter: blur(16px); background: rgba(255, 255, 255, 0.75)`），带有极细微的白边描边与卡片阴影。
   - **悬浮特效**：悬浮时卡片整体上浮 `6px`，卡片描边亮起，背部产生淡紫色霓虹发光晕开的阴影特效。
   - **动态徽章 (Live Badges)**：
     - **每日练习**：未打卡时卡片角标显示闪烁呼吸灯“今日待挑战”；已打卡则变为绿色对勾徽章。
     - **错题本**：右上方带有呼吸发光的红色计数圆点（如 `8`）。

2. **玻璃感面包屑返回条**
   - 进入各个子模块专注工作区时，控制台淡出。新页面顶部固定一根半透明粘性返回条。
   - 提供后退箭头按钮 + `返回控制台` 标签，悬浮时箭头向左做平滑弹性微移。
   - 标签右侧以面包屑层级展示当前节点位置（如：`刷题中心 / 错题本`）。

3. **子模块专属交互硬化**
   - **【每日练习】**：大卡片居中排版，选项采用 Outfit 英文字母标识圆角按钮，去除一切无关模块的视觉打扰。
   - **【模拟组卷】**：
     - 组卷配置面板与试卷预览列表采用 1.2:1 左右双栏玻璃卡排版。
     - 开始考试后切换至全屏禅定工作区，倒计时时钟加粗显示。右侧圆形数字答题卡面板在交卷后直接变为红（错）绿（对）徽章，点击时平滑滚动至题目锚点。
   - **【错题本】**：
     - 左侧快速再练提供卡片重做功能，支持提交答案后即时评估，答对后触发轻量烟花或消灭动效。
     - 右侧错题列表提供一键滑入归档、移出操作。

---

### 第三部分：动效与样式规范 (Transitions & Styles)

1. **切换过渡动效**
   - 切换子模块时，为当前 `activeModule` 外层包裹 Vue 3 `<transition>`，使用自定义的 `fade-scale` 过渡类。
   - 使得旧页面略微缩小淡出，新页面略微放大自下方滑入（缩放比例 `0.97` 到 `1.0`，位移 `10px`）。

2. **微动效与状态**
   - 呼吸灯徽标使用 CSS `@keyframes pulse` 控制大小和外发光范围。
   - SVG 进度环与雷达多边形在首次挂载页面时，通过 `transition` 控制 `stroke-dashoffset` 和顶点坐标，实现从 0 渐进展开的动态渲染。
   - 所有按钮与卡片 hover 状态使用统一的贝塞尔曲线 `transition: all 0.3s cubic-bezier(0.25, 0.8, 0.25, 1)`。

## 验证标准

1. **界面表现力**：
   - 题库首页默认呈现聚合看板，包含全局正确率环形动画、SVG 技能雷达图。
   - 5 个入口卡片呈现磨砂玻璃质感，悬浮时上浮、亮起，并有微弱渐变紫色发光。
2. **交互顺畅性**：
   - 点击卡片进入对应模块，页面切换平滑，面包屑返回条在顶部粘性固定。
   - 点击“返回控制台”能自然退回控制台首页，且仪表盘动画重新流畅展开。
3. **数据一致性**：
   - 雷达图指标（如“练习量”、“准确度”、“错题消灭率”）与实际刷题统计、错题本状态（已归档/未归档数量）完美挂钩，消灭错题后能引起雷达多边形变化。
4. **编译与构建**：
   - 执行 `npm run build` 无任何 TS/Vite 构建报错，页面完全适配各种屏幕。
