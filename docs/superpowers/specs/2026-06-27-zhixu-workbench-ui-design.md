# 学枢智导「知序工作台」全局 UI 改造设计

## 目标

先统一整个前端的视觉底座与页面骨架，再分模块改造首页、认证、资源、路径、辅导、题库和个人中心。改造不改变现有路由、接口和业务数据边界。

## 已确认方向

采用方案 A「知序工作台」：学术编辑秩序与专业仪表盘结合，强调长期阅读舒适度、任务效率和数据可信度。品牌统一为“学枢智导”，移除各页面中相互冲突的 `EduAgent`、`EDU_CORE` 等名称。

## 组件策略

- 直接使用 Element Plus 及 `@element-plus/icons-vue`。
- 不创建通用基础组件包装层。
- 删除或替换不存在的 `BaseCard`、`BaseButton`、`BaseTag` 引用。
- 现有业务组件继续保留，只有业务能力明确时才新建组件。
- ECharts 继续承担数据可视化，不额外引入重复图表库。

## 第一阶段：全局视觉底座

1. 调整 `src/style.css` 中的语义颜色、字体、圆角、间距、阴影和动效变量。
2. 映射 Element Plus 的主题变量，统一按钮、输入框、表格、标签、弹窗、分页和反馈状态。
3. 清除全局负字距、超大圆角、装饰光球、玻璃拟态与不必要渐变。
4. 建立统一页面容器、标题区和响应式边距规则，但不封装为 Vue 基础组件。
5. 加入键盘焦点、减少动画和移动端 44px 触控规则。

## 第二阶段：应用外壳与首页

### 全局导航

- 桌面端使用稳定的顶部应用栏，保留五个一级模块。
- 当前模块以文字权重、底部指示线和模块色共同标识。
- 个人菜单使用 `ElDropdown`；移动端使用 `ElDrawer`。
- 去除无业务价值的时间、同步文案和装饰状态。

### 首页

- 首屏改为“今日学习指令”，突出一个主要任务。
- 学习概况使用紧凑指标行，不堆叠小卡片。
- “继续学习”和“能力画像”形成主次双栏。
- 推荐资源、每日挑战和最近记录使用清晰列表或表格。
- 所有按钮、标签、卡片直接替换为 Element Plus 组件。

## 第三阶段：业务页面

- 认证：统一品牌、表单宽度、验证反馈和辅助视觉。
- 资源：蓝色模块标识，采用任务编辑器式生成入口。
- 路径：琥珀色模块标识，保留路径画布与阶段信息。
- 辅导：会话侧栏、阅读区和固定输入区形成稳定三段结构。
- 题库：用标签页、筛选、题目列表替代展示型入口卡片。
- 个人中心：使用 12 栏网格组织身份、画像和学习历史。

`resource` 与 `path` 只共享布局和视觉变量，不合并记录、详情页面或持久化模型。

## 状态与错误

- 超过 300ms 的加载显示 `ElSkeleton` 或明确进度。
- 异步操作通过 Element Plus `loading` 状态阻止重复提交。
- 空状态提供解释和下一步操作。
- 表单错误贴近字段，接口错误提供重试路径。
- 删除等危险操作必须二次确认。

## 响应式与验收

- 验证宽度：375、768、1024、1440px。
- 移动端无横向滚动，核心任务优先于统计与辅助内容。
- 正文对比度达到 WCAG AA，图标按钮有可访问名称。
- 支持键盘操作和 `prefers-reduced-motion`。
- 每阶段执行 `npm run build`；最终通过浏览器截图检查桌面与移动端布局。

## 实施边界

- 不修改后端。
- 不改变 API 契约和路由语义。
- 不创建自有基础组件库。
- 不同时混入其他通用 UI 组件库。
- 不处理与本次 UI 改造无关的重构。
