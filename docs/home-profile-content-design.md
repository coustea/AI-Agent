# Home.vue 与 Profile.vue 内容规划

## 页面定位

- **Home.vue** — 行动枢纽：用户打开后第一时间知道"今天该做什么"，以快速导航和行动引导为主
- **Profile.vue** — 身份档案：用户查看"我是谁"，以完整的个人信息和画像详情为主

---

## Home.vue 展示内容

### 1. Hero 欢迎区
- 欢迎标语 + 画像同步状态标签
- 3 项动态行动指标：推荐学习目标 / 薄弱点数量 / 路径完成度

### 2. 推荐学习目标面板
- 推荐目标标题 + 完成度标签
- 推荐步骤列表（2-3 步）
- 行动按钮：生成配套资源 / 查看学习路径

### 3. 功能入口卡片（4 个导航入口）
- 多智能体资源生成 → /resource-generator
- 开始路径规划 → /path-planner
- 向智能导师提问 → /tutor
- 查看多维评估 → /evaluation

### 4. 学习画像雷达图
- 6 维度雷达图（知识基础 / 学习目标 / 认知风格 / 薄弱点 / 实践能力 / 交互偏好）
- 旁边展示 3 个最突出的维度标签（含变化趋势箭头）
- 薄弱点快速入口（3 项，每项带"生成资源"CTA）
- 底部链接：查看完整画像 → /profile

### 5. 最近资源流
- 最近 3 条生成资源摘要（标题 + agent 类型图标 + 一行摘要）
- 底部链接：查看全部 → /profile

---

## Profile.vue 展示内容

### 1. 用户基本信息卡
- 头像（可点击上传更换）
- 姓名、邮箱
- 一行摘要（专业 · 学历 · 院校）
- 标签：年级、学习目标
- 编辑资料按钮 → 弹出编辑对话框
- 基础信息行：学历层次 / 专业 / 院校 / 年级 / 常用语言 / 学习目标 / 正在学习的课程

### 2. 完整学习画像
- **文字画像描述**：8 个维度各自的文字说明（认知风格、学习节奏、知识基础等）
- **画像评分条**：每个维度的分数 + 进度条 + 与上次的变化趋势（↑↓→）
- **薄弱点详情**：完整薄弱点列表，每项附推荐资源类型
- **画像元信息**：置信度、版本号、更新时间、更新原因

### 3. 资源生成历史
- 可筛选的资源列表表格（全部 / 已完成）
- 列：任务名称 / 包含资源类型 / 状态 / 时间 / 操作（查看详情）
- 分页加载

### 4. 近期表现
- 区间学习时长（可选近 7 天 / 近 30 天）
- 完成任务数

### 5. 学习成长趋势
- 按课程的掌握度折线图
- 课程选择器

### 6. 画像历史版本（可选）
- 查看画像的历史变更快照
- 对比不同版本间的维度变化
