# Mentorly —— AI 教学与多模态课件创作智能体平台

**项目简介**：基于软件杯比赛项目演进的全栈 AI 学习助手，采用 Go 与 CloudWeGo Eino DeepAgent 构建单 TutorAgent 统一编排架构（替代硬编码生成工具与多 Agent 强耦合方案），支持流式教学答疑、多格式附件深度解析、联网检索，以及按需挂载只读 Skills 自主完成 Word、PDF、电子表格、Excalidraw 图解、PPT 课件与 HyperFrames 动画视频的端到端创作交付。

**技术栈**：Go 1.26、CloudWeGo Eino (ADK / DeepAgent)、Gin、GORM、MySQL、SSE、React 19、TypeScript

**核心工作与技术攻坚**：

- **小步读写约束与主子代理协同**：针对制作 10 页级 PPT/长文档时单次大体积输出易触发 JSON 参数截断、步步深度思考耗尽 Token，以及长链路检索与编写混杂导致任务跑偏、撑爆主窗口的问题，在虚拟文件系统层硬性收紧单次读取（200 行）与写入上限（220 行 / 12 KB），倒逼模型通过 `grep` 定位与 `edit_file` 小步迭代；基于 `RunLocal` 实现仅首轮规划开启深度思考、后续执行步自动关闭的 `Thinking` 中间件，以及强制单 `in_progress` 校验与连续 3 步未更新自动注入提醒的 `Todo` 中间件；拆出无思考开销的只读检索 `explorer` 与独立执行 `worker` 子代理并在事件消费层按 `RunPath` 隔离内部流，消除大参数反序列化报错与无效推理开销，显著降低主代理上下文占用，支撑单轮 40 步复杂创作任务稳定收敛。
- **分层上下文裁剪与原子摘要检查点**：针对多轮工具调用与附件累积撑爆上下文、传统字节除四低估中文及工具 Schema 开销，以及自动摘要易丢失已加载 `SKILL.md` 规范或截断 `ToolCall/ToolResult` 配对引发协议报错的问题，将静态环境固定于启动期 System Prompt、动态日期与附件下沉至 `<turn_context>` 及历史 `<attachment_ref>` 分页读取以保护上游 Prompt Cache；串联 `PatchToolCalls → Reduction → TokenBudget → ContextCompaction` 中间件链，每次调用前补齐中断悬空结果并成对清理旧工具批次（保留最新批次与活动技能），实现含工具 Schema 的中英混合 Token 估算、基于真实 `PromptTokens` 的单调上调校准与剩余窗口动态限流；在输入达窗口 80% 时触发单轮唯一结构化摘要，原子合并活动技能、最新工具对与当前请求并通过配对完整性及窗口 20% 目标校验，配合事务化检查点增量恢复历史，彻底消除长会话上下文溢出与工具链断裂报错。
- **单向流式执行链路与断连一致性治理**：针对标准 `http.Client.Timeout` 按总墙钟误杀正常流式长生成、工具调用前过渡文本与空响应重试造成前端闪屏残留，以及客户端中途断连易引发会话死锁或半截工具记录落库的问题，主导重构为 `Service → Harness → Agent` 单向无环流水线（职责解耦会话互斥锁、检查点历史装配、流式执行与持久化）；定制 HTTP `Transport` 仅保留 60s `ResponseHeaderTimeout` 防首包挂死、交由外层 `run_timeout` 管控整轮预算，收敛自动重试策略至「仅无错空响应单次重试」并配合 SSE `reset` 帧撤回中间态文本；基于 15s 心跳探测与写失败即时 `cancel` 秒级终止下游推理，落库阶段采用 `WithoutCancel` 独立事务过滤残缺工具对并通过 `visible` 复合索引分离用户问答与内部轨迹，保障高并发流式交互的实时性与账本强一致。
- **多租户零信任隔离与工具错误自愈**：针对智能体读写文件与执行本地脚本时的跨会话越权、符号链接逃逸、篡改官方 `SKILL.md` 及子进程泄露服务端密钥等安全风险，建立基于运行期 `Context` 的零信任身份边界（工具与存储层一律从 `Principal` 提取租户目录，绝不采信模型入参）；封装虚拟文件系统隔离挂载会话读写 `/workspace` 与严格只读 `/skills`，结合逐级 `EvalSymlinks` 与下载端 `O_NOFOLLOW` 阻断目录穿越与软链接逃逸；在最外层实现 `ToolGuard` 中间件拦截跨平台高危命令与技能目录写入，在跨平台 `execute` 中剥离 `JWT_*/LLM_*/MYSQL_*` 等敏感环境变量，并将可恢复工具报错脱敏宿主机物理路径后转为模型修复指引，实现安全边界零突破与常见参数/读写超限错误的模型自主纠偏，后端 12 个测试包全量通过 `-race` 竞态与安全专项验证。
