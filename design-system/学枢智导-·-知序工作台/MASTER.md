# 学枢智导：知序工作台设计系统

> 本文件是全局视觉与交互规范。页面级规则只能补充本文件，不能改变组件来源、颜色语义和可访问性要求。

## 1. 设计方向

- 产品类型：AI 辅助学习与知识生产工作台
- 核心气质：理性、安静、精密、可信
- 视觉概念：学术编辑秩序 + 专业仪表盘
- 识别元素：编号式章节、3px 模块标识线、等宽数据刻度
- 信息密度：桌面端中高密度，移动端按任务优先级折叠

系统不使用玻璃拟态、装饰光球、大面积渐变、悬浮卡片墙或营销型巨幅 Hero。

## 2. 技术约束

- 直接使用 Element Plus 组件与 `@element-plus/icons-vue`。
- 不创建 `BaseButton`、`BaseCard`、`BaseTag` 等通用包装组件。
- 统一样式通过全局语义变量、Element Plus CSS Variables 和页面 class 实现。
- 业务组件只承载业务能力，例如路径画布、资源编辑器和辅导会话。
- `resource` 与 `path` 仅共享视觉规范，记录、详情页和持久化模型保持独立。

## 3. 颜色

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| Paper | `#F6F7F4` | 应用背景 |
| Surface | `#FFFFFF` | 工作区、表格、弹窗 |
| Ink | `#17202A` | 标题与正文 |
| Secondary | `#58636F` | 辅助文字 |
| Border | `#D9DED8` | 边框与分隔线 |
| Primary | `#1856D8` | 主操作、焦点与资源模块 |
| Success | `#147D64` | 完成、掌握度、正向状态 |
| Path | `#C98216` | 学习路径模块 |
| Evaluation | `#7B4CA5` | 测评与题库分析 |
| Danger | `#C64747` | 错误与危险操作 |

模块色只用于标识线、图标、状态和数据，不作为大面积页面底色。状态不得只依靠颜色表达，必须配合图标或文字。

## 4. 字体与数据

- 界面与中文正文：`Noto Sans SC`，回退到 `PingFang SC`、`Microsoft YaHei`。
- 英文与数据：`IBM Plex Sans`；表格数字使用等宽数字特性。
- 代码与精密指标：`JetBrains Mono`。
- 字号阶梯：12、14、16、18、24、32px。
- 正文移动端不小于 16px；行高 1.5 至 1.7；字距固定为 0。

## 5. 几何、间距与层级

- 间距遵循 4/8px 节奏：4、8、12、16、24、32、48px。
- Element Plus 控件默认高度 40px，移动端关键操作不低于 44px。
- 按钮、输入框圆角 6px；卡片、表格容器和弹窗圆角 8px。
- 胶囊圆角只用于状态标签和头像。
- 页面最大宽度 1440px，桌面边距 24至32px，移动端边距 16px。
- 常规容器使用 1px 边框；阴影仅用于弹窗、下拉层和悬浮层。

## 6. Element Plus 规则

- 每个页面只保留一个 `type="primary"` 主操作。
- 图标按钮必须使用 `ElTooltip` 或 `aria-label`。
- 表单使用可见 `ElFormItem` 标签，错误显示在对应字段附近。
- 异步按钮使用 `loading` 并禁止重复提交。
- 复杂列表使用 `ElTable`、`ElPagination`、`ElSkeleton` 和明确空状态。
- 选项集合使用 `ElTabs`、`ElSegmented`、`ElSelect`，二元设置使用 `ElSwitch`。
- 危险操作使用 `ElPopconfirm` 或 `ElMessageBox`。

## 7. 导航与页面骨架

- 桌面端保留固定顶部导航，品牌、五个一级模块和个人操作保持稳定位置。
- 小于 1024px 时收起为 Element Plus 抽屉导航，不混用同层级底部导航。
- 页面结构统一为：页面标题区、主要任务区、辅助信息区。
- 三层及以上页面显示 `ElBreadcrumb`，返回后保留筛选与滚动状态。
- 首页是学习控制台，不使用营销型介绍区。

## 8. 动效与可访问性

- 微交互 150至220ms，仅动画 `opacity` 与 `transform`。
- 不使用循环漂浮、发光脉冲和布局位移动画。
- 支持 `prefers-reduced-motion`。
- 普通文字对比度至少 4.5:1，焦点环宽度 2至3px。
- 键盘顺序与视觉顺序一致；图标、图表和空状态提供可读文本。
- 在 375、768、1024、1440px 宽度验证，无横向溢出。

## 9. 禁止项

- 不引入第二套通用 UI 组件库与 Element Plus 混用。
- 不自制 Element Plus 已提供的按钮、卡片、标签、弹窗、表格和表单控件。
- 不使用 emoji 或手绘 SVG 作为结构图标。
- 不使用任意硬编码色值破坏语义颜色体系。
- 不通过悬停缩放改变布局边界。
